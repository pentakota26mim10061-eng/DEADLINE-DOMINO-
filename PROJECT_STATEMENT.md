# PROJECT STATEMENT

## Project Title
**Deadline Domino – Academic Workload & Task Flow Planner**

## Problem Statement

Students often have several academic tasks at the same time. A normal task list can show what has to be done, but it does not clearly show which pending task can create the greatest workload pressure.

A student may therefore spend time on smaller tasks while a high-effort or high-urgency task remains unfinished.

## Proposed Solution

Deadline Domino is a command-line Python application that stores academic tasks in a list and calculates a workload score for each task.

The score is:

**Workload Score = Estimated Hours × Urgency**

Urgency is represented by:

- 1 – Low
- 2 – Medium
- 3 – High

The application repeatedly selects the pending task with the highest score and displays it as the next task in the Domino Order.

## Objectives

1. Create a simple academic task management program.
2. Apply Python functions to divide the problem into smaller parts.
3. Use lists and nested lists to store task information.
4. Use conditional statements and loops for decision-making.
5. Apply a simple selection-based algorithm to order tasks.
6. Calculate total, pending and completed workload.
7. Produce a subject-wise workload summary.
8. Demonstrate input validation and error handling through basic conditions.

## Scope

The project covers:

- Task creation
- Task display
- Workload calculation
- Task ordering
- Completion
- Deletion
- Workload reporting
- Subject summary

The project intentionally does not include a database, GUI, cloud storage, login system or external Python package.

## Expected Outcome

The final application should help a student understand the workload created by pending academic tasks and identify the tasks that deserve attention first.

## Technology

- Programming Language: Python
- Interface: Command Line
- Storage during execution: Python lists
- External packages: None
